The development of the Software Design Document (SDD) prior to implementation provided a structured framework for identifying potential performance, scalability, and system design challenges early in the project lifecycle. For The Gaming Room’s Draw It or Lose It, the design emphasized support for concurrent users, enforcement of unique game and team names, and reliable cross-platform accessibility. A particular strength of the project was the analysis of system architecture and design constraints, which established a robust foundation for future development efforts. In retrospect, the document could be strengthened by incorporating a more detailed discussion of deployment strategies and testing methodologies. Throughout the design process, user requirements remained a primary consideration, with a focus on system responsiveness, reliability, and overall user experience. This project underscored the importance of adopting a structured, architecture-driven approach to software development. Moving forward, I intend to continue leveraging modular design principles, UML modeling techniques, and containerization technologies to support maintainability, scalability, and efficient software delivery. Ultimately, this experience reinforced that successful software engineering extends beyond writing functional code; it requires thoughtful planning, strategic design decisions, and a continuous focus on aligning technical solutions with organizational goals and user needs.
